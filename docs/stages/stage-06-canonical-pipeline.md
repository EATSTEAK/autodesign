# Stage 06: Canonical Pipeline

## Objective

Implement the canonical Autodesign pipeline for interview, story, brand, UX, view taxonomy, navigation, screen state, and primary visual anchor proposal artifacts.

## Success Criteria

- Canonical subskills can generate their declared canonical artifacts from real project input files.
- Coverage matrix and decision log are created and updated.
- UX platform selection remains a hard gate when missing.
- Primary visual anchor screens are proposed but not auto-approved.
- Artifact graph and manifest state are updated after canonical generation.
- No image generation, Pencil operations, visual reference generation, DS generation, prototype generation, or handoff generation is implemented in this stage.

## Implementation Notes

- Use deterministic scripts for artifact writing and state updates where possible.
- Canonical artifacts are source of truth.
- Visual anchor proposal is canonical planning only; selected visual references belong to Stage 07.
